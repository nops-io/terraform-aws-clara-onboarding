# Security policy

## Reporting a vulnerability

Report security issues privately. Do not open a public issue.

Use [GitHub private vulnerability reporting](../../security/advisories/new) on this repository. If you cannot use GitHub, email
support@nops.io with "Security" in the subject.

Include the module version, the inputs involved, and the steps to reproduce. We will acknowledge the report and keep you updated
until it is resolved.

## Supported versions

Fixes are released for the latest minor version.
